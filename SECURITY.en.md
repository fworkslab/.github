# Security policy

[Русский](SECURITY.md)

## How to report a vulnerability

Do not open a public issue. Use the **Report a vulnerability** button on the
Security tab of the relevant repository — GitHub delivers the report to the
author privately.

## What counts as a vulnerability

- code running where it should not;
- network traffic, if the project promises to work locally and send nothing out;
- reading or modifying files outside the project's own data.

## What does not count

- vulnerabilities in third-party dependencies — report those to whoever
  releases them;
- mistakes in the content, translations or layout.

## What happens next

- acknowledgement of the report — within a few days;
- assessment and a plan — within two weeks;
- a fix — in the next release.

## Public disclosure

Details are not published before the fix is out. Once the release is published,
the discussion may become public if you agree to that.
